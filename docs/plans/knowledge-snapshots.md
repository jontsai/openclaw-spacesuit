provider-independent tree/excerpt snapshot for Command Center. No recursive scan
outside the named roots, no symlink/FIFO access, no query execution and no QMD claim.

Test hierarchy, bounds, redaction, unsafe inputs and profile mismatch. Pilot with
synthetic content; no live workspace activation.
